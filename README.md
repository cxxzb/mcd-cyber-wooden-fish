## 项目简介

「麦门功德+1 · 赛博木鱼」是一个面向**打工人**的趣味解压 Skill。  
你只需在对话框里说一句“敲一下木鱼 / 功德+1”，它就会**真实调用麦当劳 MCP**，  
从真实在售餐品里随机“显化”一份麦门美味作为供奉，并回赠一句打工人口语祝福。  
累计的功德可以生成一张可分享的「今日麦门功德证书」，拿去朋友圈赛博修行。

把电子木鱼这个全民解压梗，和麦当劳的单品世界结合，让品牌触点变成打工人的情绪陪伴。

## 功能特性

- 🪵 **赛博木鱼**：说“敲 / 木鱼 / 功德+1”即触发，每次**真实调用麦当劳 MCP** 取真实在售单品当“显化”
- ✨ **顿悟暴击**：连敲 3 下以上触发暴击，一次显化三份“圣品”，功德翻倍，手感更爽
- 🎴 **供奉池抽卡**：真实单品按稀有度分档（普通🤍 / 稀有💙 / 隐藏💜 / 限定🧡），欧皇出限定，攒“麦门图鉴”
- 🍟 **麦门优惠套餐**：内置 1+1 随心配、巨无霸 / 麦辣 / 板烧套餐、早餐套餐、欢聚分享桶等常见超值组合，参考价对比「省多少」，一键「🎲 抽今日套餐」帮你决定吃啥
- 🏆 **功德段位（10 级进化）**：见习木鱼僧 → 木鱼居士 → 麦门行者 → 麦门方丈 → 金拱门长老 → 赛博活佛 → 巨无霸尊者 → 麦乐菩萨 → 金拱门佛祖 → 麦门至尊，角色逐级换装（工帽 / 念珠 / 唐僧金冠锡杖 / 墨镜 / 金身 M 光环 / 莲花宝座），晋升隆重播报
- 💬 **打工人黑话祝福**：周报 / 需求评审 / 发版夜……一大库梗文案随机不重样
- 🔥 **连续修行**：按本地日期记录连续修行天数，断签重置，修行越久称号越响
- 🧩 **零配置可玩**：内置离线兜底餐品池，未配置 Token 或 MCP 不可达时自动降级，核心玩法照常体验
- 📜 **今日功德证书**：生成带日期与当日真实活动的可分享卡片（图像）
- 🍀 **宜忌彩蛋**：说“今日运势 / 抽签”触发轻量宜忌签，“下下签”提示敲木鱼化解

## 安装与使用

### 1. 获取麦当劳 MCP Token

前往 <https://open.mcd.cn/mcp> ，用手机号验证登录后，在「控制台」激活并复制 Token。

### 2. 配置 MCP

复制本项目中的 `mcp-config.example.json`，将 `${MCD_MCP_TOKEN}` 替换为你的真实 Token，  
并在支持 MCP 的客户端（**推荐 WorkBuddy**）中导入。

### 3. 在 WorkBuddy 中使用

左侧【连接器】→【自定义连接器】→【配置 MCP】导入上面的配置并启用，  
然后在对话框里说“敲一下木鱼”，即可开始赛博修行。

## 使用示例

网页版三种玩法（全程按键交互，无需打字）：

1. **🪵 敲木鱼**：点击大木鱼，一声传统木鱼"笃"立即显化一份真实餐品（带稀有度标签与真实大卡数），每 3 连击触发「✨顿悟暴击」显化三圣品、功德 +3
2. **🎴 运势转盘**：8 个扇区由真实餐品 + 当日真实活动生成，转动抽签，抽中「功德翻倍」直接 +5
3. **📜 功德书**：一键生成 Q 版证书卡片（段位 + 图鉴 + 当日真实活动彩蛋），可保存图片分享朋友圈
4. **🍟 优惠套餐**：常见超值套餐组合一览（含参考价与「省 X 元」），点「🎲 抽今日套餐」随机高亮一份，选择困难症福音

WorkBuddy 对话版：在对话框说"敲一下木鱼"，AI 调用同样的麦当劳 MCP 工具完成显化（详见 `SKILL.md`）。

## 技术架构

- **能力来源**：麦当劳官方 MCP Server（`https://mcp.mcd.cn`，Streamable HTTP 协议）
- **项目形态**：网页应用（按键式木鱼 / 运势转盘 / Q 版功德书）+ WorkBuddy Skill 对话版双形态
- **后端**：`server.js`（Node.js 零依赖），代理调用麦当劳 MCP 并做短时缓存，Token 只从环境变量 `MCD_MCP_TOKEN` 读取
- **前端**：`index.html` 单文件页面，木鱼点击动画 + Web Audio 合成"咚"声 + SVG 转盘 + html2canvas 证书导出
- **真实调用工具**：`query-meals` / `list-nutrition-foods`（核心）、`now-time-info`、`campaign-calendar`（详见 `MCP_INTEGRATION.md`）

## 本地运行

```bash
# 1.（可选）设置 Token 启用 MCP 实时数据；不设置则自动使用内置离线兜底餐品池，照样能玩
export MCD_MCP_TOKEN=你的token            # macOS / Linux
# Windows PowerShell: $env:MCD_MCP_TOKEN="你的token"

# 2. 启动（无需 npm install，零依赖）
node server.js

# 3. 打开 http://localhost:8787
```
